이 계획은 프로젝트의 과제3을 완료하기 위한 목표·작업 순서·산출물·확인 기준을 정리한다. GUI-02 일부 시연 도구의 기존 구현·검증 근거를 확인했으며 최소 Core 계약·Mock·확인용 Windows Forms 폼을 구현·검증했다. 다섯 영역 전체와 실제 Core 연결은 남아 있다. 기존 코드의 재사용 범위는 착수 전에 대조한다. 아래 작업 순서와 시험 항목은 요구사항·공통 규칙·데이터·기능명세를 기준으로 제안한 초기 계획이다.

2배경과 목적

공통 명세를 기반으로 Windows Forms의 MainForm 안에 Dashboard·Map·Alarm·History·Command 영역을 구성하고, Mock AMR로 독립 실행 가능한 GUI와 DataProvider 인터페이스를 제공한다. Windows Forms 선택은 2026-10-25 사용자의 기술 결정이며 원문 요구에서 지정한 기술로 해석하지 않는다.

3용어 설명

용어 쉬운 설명
GUI 사용자가 상태를 확인하고 명령을 입력하는 화면이다.
Mock 실제 AMR·Core 대신 정해진 시험 데이터를 제공하는 대체 구현이다.
DataProvider 화면 데이터 조회·변경 통지를 제공하는 접점이다. 명령 요청은 별도 ICommandDispatcher를 사용하며 채택 계약과 남은 상세는 D-11에서 관리한다.
Map / Marker 장비 위치를 보여 주는 지도 영역과 장비를 나타내는 표시다.
History 과거 이벤트를 조회하는 정보다. 현재 상태나 현재 알람과 구분한다.

  • 직접 연결 지도 결과의 브라우저 DOM·화면·API 표본141개는 MQTT 연동 전 모드의 근거다. 최종 MQTT 브라우저 표시와 수신 로그의 대조를 같은 실행으로 연결하는 것이 남았다.
  • 다음 결과물은 MQTT 송수신 PR 다음의 별도 지도 PR로 제안한다. 기존 지도/시작·종료·검증 도구를 재사용하고 README의 MQTT 미구현 안내를 보완한다. 대상 파일·완료조건·재시험 조건은 과제2의 담당 계획을 따른다. 새 제품 구현·PR 생성은 이번에 수행하지 않았다.
