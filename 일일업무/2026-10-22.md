## 추가 진행 — 사용자가 편집할 지도 시연 설정 분리

- 사용자 요청: 설정 파일을 따로 묶어 직접 바꿀 수 있도록 변경.
- 실제 구현: 코드 저장소의 config/map-demo/settings.json 한 파일에서 지도 행·열/장애물·AMR ID·출발점·경유점 순서·이동 간격·지도 포트·MQTT 접속/송신 주기를 수정하도록 연결했다. 같은 폴더에 항목별 안내를 두었다. 서버 시작 시 읽어 고정하며 재빌드 없이 서버 재시작 후 적용한다. 이전 경유점 입력·제품 콘솔 설정은 보존했다.
- 검증: 최종 지도 자동103건(실패·건너뜀0), 실제 설정 파일 연동6개, 실제 MQTT 회귀15개 통과. 3×8/100ms/열7 목적지와 2×3/180ms/변경 경유점이 실제 관제 수신으로 반영되고, 실행 중 파일 수정은 유지·재시작 후 변경됨을 확인했다. stepIntervalMs=0은 서버 시작 전 오류1이다.
- 발견·수정 이력: 첫 자동시험 컴파일의 xUnit using 누락을 수정했고, 이후101건 통과를 보존한다. 첫 실제 MQTT 회귀에서는 최종 수신 전 계산 도착이 Completed로 노출되는 시점을 발견했다. 동일 잠금에서 WaitingForTelemetry로 전환하도록 수정하고 회귀2건을 추가한 뒤103건·실제15개를 재실행했다. 이전 실패 근거를 삭제하거나 통과로 바꾸지 않았다.
- 화면·자원: 이번에는 브라우저에서 기본5×6·W1/W2/G·설정 파일 경로·0.6초·수신 대기를 직접 확인하고 화면을 저장했다. 변경 크기별 화면 배치 시험은 별도 미실행이다. 시험 프로세스는 종료0, 시험용 Broker는 제거, 기존 컨테이너는 유지했다. 사용자 지도59344·기존 Broker1884는 실행 중이다.
