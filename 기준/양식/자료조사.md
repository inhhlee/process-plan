# [조사 주제]

<a id="writing-guide"></a>

**작성 안내**

- Markdown을 수정 원본으로 사용한다. 수정·추가와 미리보기가 쉬운 형식이며 공통 양식으로 작성 형태를 맞춘다.
- 아래 다섯 항목의 순서를 유지한다. 실습이 없는 주제는 예시·실습 절을 생략할 수 있다.
- 조사 단계에서는 근거와 설명을 충분히 작성하고 출처의 내용과 작성자의 해석을 구분한다. AI를 활용한 내용도 사실관계와 출처를 확인한다.
- 근거·상태·완료·변경 기준은 [공통 작성 규칙](../공통%20작성%20규칙.md)을 따른다. 발표 자료는 조사 내용 중 필요한 부분을 선정해 별도로 구성한다.
- 기존 문서는 같은 파일을 갱신하고 본문 버전을 수정한다. 별도 제출본이 필요할 때는 `주제_작성자_v버전.md`로 구분할 수 있다.

## 1. 제목 및 기본 정보

- 문서 구분: 빈 양식 — 실제 조사 문서를 작성할 때 복사
- 주제: 미작성
- 작성자: 미작성
- 작성일: 미작성
- 수정일: 미작성
- 버전: v0.1 초안
- 관련 프로젝트·과제·기능 ID: 미작성 또는 해당 없음과 이유
- 관련 계획·요구사항 링크: 미작성
- 작성 기준: [이 양식의 작성 안내](#writing-guide)

저장 위치는 해당 과제의 `산출물/` 등 조사 결과를 관리할 곳으로 정한다. 수정 원본은 같은 파일로 유지하고 버전은 본문에 기록한다.

복사한 뒤 작성 기준·검증결과 양식 등의 상대 링크를 새 문서 위치에 맞추고, 실제 대상이 열리는지 확인한다.

## 2. 조사 개요

- 조사 범위: 미작성

| 미작성 | 미작성 | 문서명·버전·페이지 또는 절·링크 입력 | 미작성 |

| 입력·조건 | 확인 절차 | 예상 결과 | 실제 결과·판정 | 근거 |
