## 목적

실제 Broker를 거쳐 들어온 Heartbeat의 Topic과 원문을 시험 콘솔에서 확인한다.

- 먼저 익힐 내용: Topic은 메시지 주소, 구독은 받을 주소를 등록하는 작업이다. 처음에는 장비 하나·메시지 한 종류만 확인한다.

## 작업 범위와 대상

- 개발 위치: `C:\amr-control-system-demo`. 대상: Mqtt/ 구독 처리(생성 예정), 기존 콘솔 Program.cs, README, 필요한 구독 경계 시험.
- 라이브러리·콘솔·시험 프로젝트는 준비돼 있다. 제품 소스는 현재 없으므로 위 모듈은 새로 만들거나 선행 작업에서 생성한 파일을 보완할 예정이며, 착수 시 실제 구조·기존 변경을 대조한다.
- 생성 예정 Mqtt/의 구독 처리와 기존 콘솔에 amr/+/heartbeat 수신을 추가한다. 발행자는 Mosquitto의 시험 명령을 사용하고 실행 방법을 README에 남긴다.
- 검사 전 원문은 진단용으로만 표시한다. 정상 모델 전달·AMR 생존 갱신은 COM04-A 이후에 연결한다. 비밀정보나 임의 대용량 Payload 전체를 로그에 남기지 않는다.
- 발행·구독 QoS 0, Retain=false와 실행별 Client ID를 적용한다. 새 실습 주소는 준비 결과 127.0.0.1:1884이며 명세의 기존 1883 시험 주소를 그대로 사용하지 않는다.
