## 작업 순서

1. Compose의 프로젝트·서비스·포트·마운트와 Broker의 역할을 확인한다.
2. 현재 Docker CLI·설치 이미지·포트·관리 위치를 조회하고 `compose -f docker/compose.yaml config --quiet`를 실행한다.
3. 같은 Compose 정의로 `up -d mosquitto`, `ps`, `logs`를 실행해 기동·설정 로딩·포트 공개를 확인한다.
4. 이 프로젝트의 `stop mosquitto`로 중단하고 다시 기동한다. 실제 접속 주소와 로그를 남긴다.
5. 설정 변경이 필요하면 원인·영향을 기록하고 README·증거를 연결한다. 후속 A2 착수 시에도 현재 실행 상태를 재확인한다.

기존 사용자 Broker·다른 작업의 서비스·데이터를 중단·삭제·초기화하지 않는다. 새 SDK·Docker·Broker 도구 설치는 포함하지 않는다. 실행 불가는 환경 원인과 재개 조건을 기록한다.

## 제외 범위

C# 연결 코드, MQTT 접속·메시지 시험, 새 시험 프로젝트, Ctrl+C 수명주기 구현, 자동 재접속. A1 완료는 Broker 실행 준비 완료이며 MQTT 접속 성공이 아니다.
