## 목적

프로젝트 전용 Mosquitto를 실행하고 상태·로그·중단 방법을 직접 확인한다. Broker는 MQTT 연결을 중계하는 서버이며, 이번 작업은 서버 준비까지다.

## 이번에 할 일

- 기존 `docker/compose.yaml`·`docker/mosquitto/config/mosquitto.conf`를 읽고 `amr-demo / mosquitto`, 루프백 1884 설정을 확인한다.
- 기존 코드 README의 명령으로 해당 Broker만 기동하고 상태·로그·실제 관리 위치를 기록한다. 수정이 필요하면 이 설정과 README·증거로 범위를 한정한다.
- 새 실행 데이터를 생성할 수 있으나 기존 Broker·데이터를 중단·삭제·초기화하지 않는다.

## 진행 순서

1. README의 Docker CLI 경로를 현재 PC와 대조하고 `compose config --quiet`로 설정 모델을 확인한다.
2. 해당 Compose의 `up -d mosquitto`, `ps`, `logs`를 실행해 기동 결과를 확인한다.
3. 해당 프로젝트만 `stop mosquitto`로 중단하고 다시 기동되는지 확인한다. 다음 접속 작업에 사용할 실제 주소를 기록한다.
