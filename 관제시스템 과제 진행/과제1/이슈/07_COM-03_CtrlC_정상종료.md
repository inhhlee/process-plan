## 목적

한 번 접속하고 끝내던 콘솔을 연결 상태로 유지하고, Ctrl+C를 누르면 정상 정리·종료하도록 보완한다. 다시 실행할 수 있는 정상 수명주기를 완성한다.

## 진행 순서

1. 종료 요청을 받으면 연결 해제를 기다리고 자원을 정리한 뒤 종료 코드 0을 반환한다.
2. 실제 Broker에 접속한 콘솔에서 Ctrl+C로 종료하고 재실행한다. ID별로 이전 연결과 새 연결을 구분한다.
3. 시험 대역으로 정상 상태 변화·명시적 종료·자원 정리를 확인한다. 실제 Broker 결과와 자동 시험 결과를 따로 기록한다.

## 완료조건

- [ ] 승인 후 연결을 유지하며 연결 전·연결 후·명시적 종료 상태를 구분한다.
- [ ] Ctrl+C 후 미처리 예외·자원 잔류 없이 종료 코드 0이다.
- [ ] 새 실행의 고유 ID로 정상 접속하며 이전 세션이 남지 않는다.
- [ ] 정상 수명주기 동작 자동 시험·실제 Broker 확인·관련 빌드가 성공한다. A1~A3 근거를 기존 Issue #4의 완료조건에 연결한다.

## 시험 방법과 예상 결과

예정 시험이며 현재 결과는 미검증이다.

| 입력·절차 | 예상 결과 |
| --- | --- |
| 실제 연결 뒤 Ctrl+C | 명시적 해제·정리·정상 종료 0 |
| Ctrl+C 뒤 새 실행 | 새 ID의 정상 접속·정상 종료 |
| 시험 대역에서 정상 연결·종료·반복 정리 | 연결 승인 전 성공 없음, 종료 후 상태·정리 결과 일치 |

## 제외 범위

접속 대기 중 Ctrl+C·늦은 접속 결과는 B3, 비정상 단절·종료 경합은 C 작업에서 검증한다. 업무 메시지·AMR Heartbeat·자동 복구·GUI·Core·DB는 포함하지 않는다.
