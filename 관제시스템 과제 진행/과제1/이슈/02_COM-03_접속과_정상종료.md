| 대상 | 현재 상태·작업 내용 |

개발용 제안 설정은 호스트 `127.0.0.1`, 포트 `1884`, MQTT 5, Clean Start, 실행마다 고유 Client ID, KeepAlive 5초, 최초 접속 대기 제한 3초다. 호스트·포트·접속 대기 제한은 실행 인자로 지정할 수 있게 하고 적용 설정·Client ID를 출력·README·증거에 남긴다. 기존 1883 Broker나 기존 프로그램의 Client ID를 사용하지 않는다. 패키지를 임의로 최신화하지 않는다.

연결 요청 중과 실제 연결됨, 명시적 종료 후를 구분한다. 성공한 MQTT 접속 승인을 받은 뒤에만 `Connected`를 출력한다. 연결된 콘솔은 Ctrl+C까지 유지하고, 종료 요청 시 연결 정리를 기다린 뒤 종료 코드 0으로 끝내며 자원을 해제한다. 최초 접속 실패를 성공으로 숨기지 않는 최소 처리도 포함한다. 오류 종류·입력 경계·접속 중 취소의 상세 검증은 COM03-B에서 보완한다.

이번 실제 시험에서는 준비한 프로젝트 전용 Broker의 기동·상태·로그를 확인한다. 포트 사용·Docker·이미지·마운트 문제를 MQTT 소스 실패와 구분한다. 기존 사용자 Broker를 중단·초기화하지 않으며 SDK·Docker·Broker를 새로 설치하지 않는다. 새 Broker가 실행되지 못하면 실제 접속 시험을 미검증으로 남기고 환경 원인·재개 조건을 기록한다.
