# 과제1 검증결과 위치 안내

이 파일은 기록 위치를 안내한다. 실제 시험 결과나 빈 양식 본문을 주간 폴더에 중복 관리하지 않는다.

- 새 시험 기록은 [검증결과 빈 양식](../../../양식/검증결과.md)을 복사해 과제1의 `산출물/`에 실행별 파일로 작성한다.
- 기존 실행 결과: [2026-10-05 개발환경 검증결과](../산출물/2026-10-05_개발환경_검증결과.md)
- 다음 시험 계획: [COM-01 Heartbeat 최소 송수신](../과제계획.md#com01-test)

실제 송수신 시험을 수행하기 전에는 새 결과를 통과로 표시하지 않는다.
