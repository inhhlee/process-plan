이 계획은 프로젝트의 과제2를 완료하기 위한 목표·작업 순서·산출물·확인 기준을 정리한다. 2026-10-20 사용자는 과제1의 남은 개발을 보류하고 과제2를 먼저 진행하도록 요청했다. 10/21 우선 목표였던 설정 로드 → AMR 1대 생성 → 경로 이동·도착의 첫 실행본은 PR #35~37로 develop에 반영됐다. 10/22 현재 #28·#32~34는 완료 종료이며, 다음 결과물은 보존한 MQTT 송수신과 지도 시연의 정식 반영으로 제안한다. 과제2 전체 검증·과제1 전체 완료·책임님의 검토 및 납품 일정 승인은 남아 있다.

**2026-10-21 추가 문서 반영:** [사용자 추가 요구](../명세/요구사항정의.md#grid-pathfinding-scope)의 격자 최단 경로 비교를 후속 작업으로 추가한다. 새 기능은 미착수·미검증이며 이번 요청은 명세·계획 작성까지다. 아래의 첫 실행본 일정·상태 설명은 앞선 계획/조회 이력이고, 현재 기존 구현의 근거는 위 실제 진행 기록을 따른다. #33 검증 통과를 격자 탐색 성공으로 확대하지 않는다.

## 2. 배경과 목적

이동·상태 변경·알람 발생·명령 응답을 제공하는 독립 시뮬레이터를 구성하고, 수량·초기 좌표·속도·이동 경로·장애 시나리오를 설정 파일로 바꾸어 시험할 수 있도록 한다.

## 3. 용어 설명

| 용어 | 쉬운 설명 |
| --- | --- |
| 가상 AMR | 실제 로봇 대신 위치·상태·알람·명령 응답을 만들어 주는 시험 프로그램이다. |
| Telemetry | AMR의 위치·속도·상태 등 현재 정보를 전달하는 데이터다. |
| State / Alarm | 운행 상태와 장애 알림이다. 상태 변화와 알람의 관계는 D-05에서 정한다. |
| Command / ACK | AMR에 보내는 동작 요청과 응답이다. 명령과 응답은 같은 요청 ID로 연결한다. |
| 시나리오 설정 | 수량·초기 좌표·속도·경로·장애 조건을 코드 수정 없이 바꾸기 위한 입력이다. |
| 격자 경로 탐색 | 통행 가능한 셀 연결에서 최소 이동 횟수·거리를 찾는다. 다익스트라와 A*를 같은 조건에서 비교한다. |

## 6. 개발 로드맵

### 선행 조건과 단계 흐름

- 공통 좌표·상태·메시지 계약을 공유한다. 과제1 전체 완료는 이번 독립 실행본의 선행 조건이 아니다. 실제 Core·GUI 없이 먼저 이동을 확인한다.
- [10/20 구성 확인](#task2-project-check)에서는 `Amr.Simulator` 콘솔 골격만 확인했다. 10/21 현재 #32 PR #35가 병합된 develop에는 설정 로더·초기 AMR 모델·전용 시험·설정 예시가 게시돼 있다. 이동 계산·실행 루프·통신은 후속이며, 기존 수신·검사·큐는 송신 연동 확인에 활용한다.
- 과제1 #6·COM05-A #29는 후속 요청으로 develop 반영·Issue 종료된 [10/20 결과](../../일일업무/2026-10-20.md)를 따른다. COM-02·COM05-B·COM-06·전체 검증 등 잔여는 [전체일정의 보류 범위](../전체일정.md#task2-priority)로 유지한다. 후속 Command 시험에는 기존 명령 콘솔을 사용할 수 있으나 시뮬레이터의 명령 수행·ACK 대조 완료로 집계하지 않는다.

> 단계 흐름: 단일 AMR 설정·생성 → 경로 이동·도착 확인 → Heartbeat·Telemetry 송신 → 수량·장애 설정 확장 → Command·State·Alarm·ACK → 독립 시험·정리

**격자 후속 범위 완료조건 — 모두 예정·미체크**

- [ ] 지도·셀 크기·고정 장애물·출발/목적지의 정상 입력과 오류 거부를 확인하고 기존 경유점 모드를 보존한다. (PF01·06·07·08)
- [ ] 두 알고리즘이 통행 가능한 4방향 경로를 반환하며 각각 알려진 정답 거리와 일치한다. 동일 최단거리의 경로 모양은 달라도 된다. (PF01·02·05)
- [ ] NoPath·입력 오류·출발=목적지의 거리0 성공을 구분하고 잘못된 이동/BUSY 전환을 막는다. (PF03·04·06·07)
- [ ] 같은 입력·독립 탐색 상태에서 거리·탐색 확정 셀 수·계산 시간을 기록한다. A*의 항상 우수함을 합격조건으로 삼지 않는다. (PF05·10)

- [ ] 지도·출발/목적지·탐색 결과·비교 수치·실제 위치를 구분해 표시하고, 재실행/선택 변경 시 이전 실행과 섞이지 않는다. (PF09·10, GUI2-PF01~03)
- [ ] 단위시험·실제 독립 실행·화면 검증을 구분해 코드/설정 버전·환경·입력·예상·실제·판정·증거를 연결하고 기존 #32/#33 회귀를 확인한다. 새 기능·과제 전체 완료와 기존 결과를 구분한다.
